# Ethera: The Stonewrought — content and provenance

**Author and creative direction:** Babuni.dev  
**Edition:** Curated public documentation, prepared 2026-10-28.

The initial public edition is adapted from the original project README and concept overview inspected on 2026-10-28, together with Babuni.dev’s instruction to publish documentation only. It deliberately summarizes rather than copies private files or their links.

The private documentation reports a first-milestone simulation and historical simulation checks. Those are source-reported results, not tests rerun for this public edition. Later design milestones must remain distinct from implemented systems.

## Included and excluded

Included: these ten standard Markdown documents describing scope, development boundaries, attribution and evidence. Excluded: implementation files and history, raw chats, player/operator records, production hosts, secrets, images, videos and other assets. Existing third-party credit is retained where relevant; no third-party media is redistributed.

These files do not establish that the project is complete, released or independently tested. Missing history stays missing; later documents can add reviewed detail without inventing it.
